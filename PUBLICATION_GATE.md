## GitHub / Pages gate

Before treating the current public projection as deployed:
1. commit the complete projection;
2. read back exact `main` HEAD;
3. confirm repository visibility;
4. confirm Pages source is `main` / `(root)`;
5. confirm the Pages workflow succeeds on the intended head;
6. inspect the live build;
7. verify critical links and product behavior.

## LinkedIn gate

Before posting:
1. confirm final live and repository URLs;
2. mechanically recheck `LINKEDIN_POST.md` against the included v1.3.0 standard;
3. confirm carousel/accessibility-companion parity;
4. publish through an authorized surface;
5. capture and read back the live LinkedIn URL/content.

## Terminal closeout
