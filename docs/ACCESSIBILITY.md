# Accessibility

The interface was designed with:
- semantic headings and labels;
- table headers for queue structure;
- a skip link;
- keyboard-focusable queue rows;
- Enter/Space row activation;
- visible focus behavior;
- text labels rather than color-only status meaning;
- responsive layout for narrower screens;
- status/result text exposed as readable content.

## Remaining boundary
This is not an accessibility certification. Final accessibility confidence requires live rendered inspection with representative browsers, zoom, keyboard-only navigation, and assistive-technology checks where applicable.

Any live rendering defect must be treated as a release defect rather than hidden by this document.
