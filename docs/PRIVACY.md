# Privacy

## Shipped data
The release uses synthetic sample records only. No intended customer, employee, prospect, or campaign production data is included.

## Runtime behavior
The static application:
- makes no network requests;
- sends no telemetry;
- sets no application cookies;
- stores no user-entered data;
- has no account or credential surface.

## Production requirements
A production implementation would require explicit decisions for data minimization, authorized data sources, role-based access, retention/deletion, audit logging, sensitive-content handling, incident response, privacy notices, and applicable regulatory obligations.

This document describes the shipped demo boundary; it is not a legal/privacy certification.
