## Public-projection rollback
If a publication repair introduces a defect:
1. preserve the failed public commit;
2. identify the last known-good public commit;
3. restore/revert or rebuild from the frozen subject plus qualified public documentation;
4. replay public manifest/checksum validation;
5. redeploy Pages;
6. read back the live site.

A backup or commit existing is not, by itself, a proven restore. Recovery is only established to the level actually tested and read back.
